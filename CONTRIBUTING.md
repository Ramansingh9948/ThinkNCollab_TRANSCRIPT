# Contributing to ThinkNCollab-Whisper

Thank you for your interest in contributing to ThinkNCollab-Whisper! We welcome contributions from developers, researchers, and open-source enthusiasts.

## How to Contribute

1. **Fork the Repository**: Create your own branch from `main`.
2. **Setup Environment**:
   ```bash
   pip install -r requirements.txt
   pip install -e .
   ```
3. **Make Changes**: Implement bug fixes, new features, or model optimization.
4. **Test Your Changes**:
   ```bash
   python3 thinkncollab_whisper.py sample_test.wav --verbose
   npm test
   ```
5. **Submit a Pull Request**: Describe your changes clearly in the PR description.

## Code of Conduct

Maintain professional, respectful, and constructive communication at all times.
